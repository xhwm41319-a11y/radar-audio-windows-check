RADAR AUDIO · WINDOWS

普通电脑也有一条 CPU 路线

这是尚待 Windows 实机验收的候选。已组装运行文件，不代表已在所有配置上运行通过。

电脑配置本包处理方式
Windows 10/11，Intel或AMD 64位，无独显CPU

Apple Silicon Mac使用单独的Mac版本

开始使用

  1. 完整解压到短的本地目录，例如 C:\RADAR\Audio。
  2. 推荐16GiB以上内存，解压后至少另留10GiB磁盘。低内存电脑先试短片段。
  3. 双击 Start-RADAR.cmd。第一次会安装包内依赖、校验文件，再打开浏览器；Python与模型均已随包提供。
  4. 导入一段音频和3–15秒参考音色，先选快速验证。转换耗时取决于电脑，页面运行预算不是预计完成时间。

若提示缺少 Visual C++ x64 运行库：使用 微软官方说明中的 X64 下载链接安装，然后重新启动。本软件不自动安装系统组件或更改系统权限。

检查和恢复

Check-RADAR.cmd 检查本机启动和任务停止；只记录本机实际结果。Retry-Failed-Install.cmd 为已明确失败的安装保留旧目录后重试。不要覆盖旧目录升级，原始音频与生成结果请自行保留。

详见 README.md。实际音频生成、质量与不同机器验收分别记录；安装成功不等于音色还原成功。
